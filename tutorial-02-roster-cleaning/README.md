# tutorial-02: 社員名簿クレンジング

**pandas のクレンジングだけを、ノートブック1枚・15分で一周する教材です。**

tutorial-01 は取り込みから出力まで通しでやるので、5章あって時間がかかります。
こちらは**間の「汚れを直す」ところだけ**を切り出して、短時間で一周できるようにしたものです。

## 何をするのか

人事システムからエクスポートした社員名簿が1枚あります。
途中で誰かが Excel で触った跡が残っていて、このままでは部門別の人数も人件費も出せません。

```
社員コード  氏名          部署      入社日        基本給        ← 全部ただの文字列
    0001    山田　太郎    営業部    2019/04/01    320000
       2    佐藤 花子     営業      2020年4月1日  298,000
    0003    鈴木　一郎    ｾｰﾙｽ      2018/10/01    ￥355,000
                              ↓
社員コード  氏名        dept_cd  division    入社日       基本給
    0001    山田 太郎   D01      フロント    2019-04-01      320000  ← 型が付いている
    0002    佐藤 花子   D01      フロント    2020-04-01      298000
    0003    鈴木 一郎   D01      フロント    2018-10-01      355000
```

生の20行を、部門別に集計できる16行にするまでを扱います。

## 使い方

`make` だけです(`start.sh` は置いていません)。

```bash
mk tutorial-02          # 起動する  http://localhost:8890/lab
mk tutorial-02-down     # 止める
mk tutorial-02-reset    # ノートブックを配り直す (自分の書き込みは消える)
```

`mk` は `~/.bash_aliases` の関数で、リポジトリのどこからでも叩けます。
このディレクトリで直接 `make up` / `make down` / `make reset` と叩いても同じです。

起動したら `01-essentials.ipynb` を開いて、上から順に実行してください。**これ1枚で終わります。**

| | |
| --- | --- |
| `notebooks/` | 配布用のノートブック。git管理 |
| `work/` | **自分がいじるほう。git管理外** |
| `data/` | 名簿と部署マスタ。読み取り専用でマウントされる |

`make up` が `notebooks/` の中身を `work/` に配ります。
**既にあるファイルは上書きしない**ので、書きかけが消えることはありません。

### VS Code から使う

ブラウザではなく VS Code の Jupyter 拡張で進めることもできます。

1. `work/01-essentials.ipynb` を開く (`notebooks/` ではなく **`work/`** のほう)
2. 右上のカーネル選択 → 「既存の Jupyter サーバー」 → `http://localhost:8890`
   (トークンは空のまま Enter)
3. `Python 3 (ipykernel)` を選ぶ

コードが動くのはコンテナの中なので、ノートブックに出てくる `/data` はそのまま通ります。

## 収録

全6節・23セル・練習3問です。節ごとに「考え方 → セルを実行 → どこを見るか」で進みます。

| 節 | やること | 出てくるもの |
| --- | --- | --- |
| 1 | まず現物を見る | `dtype=str` / `keep_default_na=False` / `value_counts` |
| 2 | 表記を揃えて、欠損を1つにする | NFKC / `strip` / `replace` で `pd.NA` に寄せる |
| 3 | 型を決める | `zfill` / 書式違いの `to_datetime` / `Int64` |
| 4 | 重複を落とす | `duplicated` / `drop_duplicates(keep=...)` |
| 5 | 部署を名寄せして結合する | 名寄せ辞書 / `merge` の `how` `validate` `indicator` |
| 6 | 使えない行を隔離して、集計する | `clean` と `rejected` に分ける / `groupby` / 検算 |

最後に、全部を1つにまとめた `clean_roster()` が手元に残ります。

**練習の答えは各問のすぐ下の `<details>` にあります。** 開いて写してかまいません。

## データ

`data/` にあるファイルは**全部目で見られる大きさ**です。
集計結果を手で数えて確かめられる、というのがこの大きさにしてある理由です。

```
roster_2024-04.csv    20行   名簿。1つの節につき1種類ずつ汚れが仕込んである
dept.csv               5行   部署マスタ (1つは廃止済み)
```

| 名前 | 中身 | 行数 |
| --- | --- | --- |
| `raw` | CSV を読んだだけ。全部文字列 | 20 |
| `dedup` | 重複を落としたもの | 18 |
| `clean` | 型を整え、使える行だけにしたもの | 16 |
| `rejected` | 使えないので隔離した行。捨てていない | 2 |

部署名の別名辞書だけは CSV にせず、ノートブックの中に `ALIAS` として書いてあります
(1枚で完結させるため)。tutorial-01 では `shop_alias.csv` としてファイルになっています。
