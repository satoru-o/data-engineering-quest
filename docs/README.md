やることは分かっているのにコードにならない、というときに読んでください。

## 通して読むときの筋道

```
01 何をする仕事か
      ↓  仕事の中身を「層」と「区切り」に分けて見る
02 パイプラインの形
      ↓  いちばん上流、取り込み層で何が起きるか
03 データは汚い                          → tutorial-01, quest-01
      ↓  整形できたとして、それを何度も流すには
04 冪等性とリプレイ                       → quest-03, 04
      ↓  差し替える単位を、どう保存すると速いか
05 列指向とParquet                       → quest-02
      ↓  流れているデータが正しいことを、どう確かめるか
06 データ品質とデータ契約                  → quest-06
      ↓  複数のパイプラインを、どう並べて回すか
07 オーケストレーションとDAG               → quest-07
```

08以降は、ここまでの上に載る個別の技術です。読む順番の決まりはありません。
